# Convertible Cranium

## Public Front Door · worthwylmedia-lang

Convertible Cranium is an **authority-bound dual-engine governance substrate** designed to separate cognition from authority, evidence from execution, and operational control from canonical truth.

> **Cognition may come from anywhere. Authority comes only through Cranium.**

This account is the public-facing front door to the ecosystem. It is intentionally **not a second production account** and does not duplicate the authoritative implementation.

## Two-account model

### Public front door

**`worthwylmedia-lang`** explains, maps, and directs.

It contains curated architecture, acquisition context, public evidence indexes, and entry points into the authoritative production repositories.

### Production system of record

**`worthwyl2022-cloud`** implements and proves.

It remains the home of production engineering, canonical authority, active verification, security hardening, historical lineage, and sensitive implementation material.

Repositories are intentionally **not duplicated merely to populate this account**. Repository history, implementation lineage, and evidence remain attached to their authoritative source.

## Cranium Commander

**Cranium Commander is the operational control surface.**

Commander can present system state, construct proposals, orchestrate governed workflows, submit authority requests, and participate in runtime safety and continuity. It does not become authoritative merely because it is the visible operator environment.

Commander does **not** replace the Kernel, create canonical authority, redefine constitutional truth, or become an independent system of record.

The production Commander/operator implementation is mapped through `worthwyl2022-cloud/cranium-ultra-platform`.

## Evidence discipline

The public surface distinguishes:

- **Verified** — supported by an executable test, artifact, or reproducible repository state.
- **Self-attested** — recorded from project execution without independent third-party verification.
- **Pending** — blocked by an identified environment, deployment, or review gate.
- **Not claimed** — deliberately outside the evidence established here.

A public description is not treated as proof merely because it sounds confident. Humanity has already produced enough PowerPoint certifications of reality.
